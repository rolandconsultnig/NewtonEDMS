1. System Overview & Architecture

NewtonEDMS is an end-to-end enterprise document management platform combining high-throughput capture, OCR extraction, AI semantic discovery, and multi-vertical business suites into a cohesive, secure workspace.

Ingestion Gateway

Direct drag & drop, physical scanner drivers, hot folder automation, and inbound email-to-folder gateway.

AI & OCR Engine

Automatic text extraction via Tesseract OCR, metadata classification, and retrieval-augmented QA.

2. Authentication & Biometrics Security

NewtonEDMS incorporates FIDO2 WebAuthn technology, allowing users to sign in without passwords using their device's native biometric hardware.

Supported Biometric Methods

  • Windows Hello (Fingerprint reader, Facial recognition camera, PIN)
  • Apple Touch ID & Face ID (MacBook, iPhone, iPad)
  • Android Biometrics (In-screen fingerprint & face unlock)
  • Hardware Security Keys (YubiKey, Titan Security Key, FIDO2 USB/NFC tokens)

How to Enroll Biometrics:

  1. Log into NewtonEDMS and navigate to Settings from the top-right user menu.
  2. In the Biometrics & Passkeys card, click "+ Register This Device".
  3. Confirm the biometric prompt on your device (Touch your sensor or glance at the camera).
  4. Your passkey is registered and securely saved!

Hacking & Security Breach Protections:

  • Account Lockout Protection: Blocks brute-force attacks by locking accounts after 5 consecutive failed logins.
  • Path Traversal Defense: Strict canonical path verification blocks directory escaping attempts (`../` and `%2e%2e`).
  • Defensive Security Headers: Full HSTS, CSP, and X-Content-Type-Options protection.
